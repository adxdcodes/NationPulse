# Combined dependencies for ALL FOUR backend services (ingestion,
# pdf-pipeline, ai-pipeline, api), for local development in one shared venv.
#
# This is a LOCAL-DEV convenience, not what you'd deploy with. In
# production, keep using each service's own requirements.txt (still
# present in services/*/requirements.txt) so e.g. the api container isn't
# also pulling in pdfplumber/PyMuPDF/pytesseract, and the ingestion
# container isn't pulling in fastapi/uvicorn. Nothing here conflicts
# between services — the shared packages below (httpx, psycopg2-binary,
# python-dotenv) were already pinned to the same version in every
# service — but bundling them is still extra weight you don't want in a
# slim per-service container image later.
#
# Build the venv from this file (see RUNBOOK.md):
#   python3 -m venv .venv && .venv/bin/pip install -r api/requirements.txt
